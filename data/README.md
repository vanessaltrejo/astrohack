# data/

Copia **sin modificar** de los archivos ligeros del paquete `AstroHack_datos_v1`
(ALMA 2013.1.00278.S, MOUS uid://A001/X120/X13a; IRAS 16293-2422).

- `espectros/W{1,2}_espectros.csv`: frecuencia LSRK (GHz) e intensidad (Jy/beam) en B_offset, B_pico y A.
- `catalogos/catalogo_local.csv`: 348 transiciones (CDMS/JPL) en frecuencia de reposo (MHz).
- `evidencia_plantilla.csv`: esquema de la tabla de evidencia.

Los cubos FITS (63 MB) no se incluyen; se obtienen del ZIP oficial.

This package makes use of the following ALMA data: ADS/JAO.ALMA#2013.1.00278.S.
Ver `LEEME_PRIMERO.txt` para el crédito completo.
