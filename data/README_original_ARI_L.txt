Additional Representative Images for Legacy (ARI-L) products

###

The ARI-L project products consist of a uniform set of continuum images and native spectral 
resolution cubes generated with the ALMA Imaging Pipeline for each source included in 
processable MOUS of cycles 2-4. The project is described in the ARI-L documentation at 
https://almascience.org/alma-data/aril. We stress that these images should be considered 
indicative of the data content but are not intended to be science-ready.

Information about the content, processing and quality of the data-reduction can be found in 
the *weblog.tgz file.
